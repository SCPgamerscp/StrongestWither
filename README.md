# Strongest Wither

**Strongest Wither** is a Minecraft Forge mod that dramatically powers up the vanilla Wither with bullet-hell attacks, higher stats, lightning, and other devastating abilities.

## Compatibility

This repository currently targets **Minecraft Java Edition 1.20.1 / Forge**. Check the version details on the download pages for released builds.

## Naming and backward compatibility

The public mod name, repository branding, and new release JAR filenames use **Strongest Wither**. Gradle builds produce `strongest-wither-<version>.jar`.

The internal Forge **mod ID remains `enhancedwither`** to preserve compatibility with existing installations, configurations, and integrations. Technical Java package and class names retain their legacy identifiers for the same reason. The Forge mod list and distribution pages display **Strongest Wither**.

Previously published files (such as `enhancedwither-1.0.0.jar`) keep their original filenames; these naming changes apply to builds published after this update.
